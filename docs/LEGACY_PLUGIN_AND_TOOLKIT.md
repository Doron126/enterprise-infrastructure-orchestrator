# Legacy Plugin and toolkit

Enterprise Infra Orchestrator v1.3.4 remains the currently published legacy Plugin, available to existing users under limited maintenance. There is no current forced retirement date, immediate deprecation or promise of indefinite support. This positioning does not imply that v1.3.4 is unsafe.

The Infrastructure Engineering Toolkit is **published as repository Markdown assets**. It is the preferred future direction for reusable engineering assessments, changes and handoffs. Its optional Markdown assets require no Plugin installation. They are a different product form, do not reproduce every Plugin behavior and are not a drop-in upgrade. Existing users are not automatically migrated and receive no automatic toolkit behavior.

The v1.3.5 hardening candidate was never published and remains unpublished. Toolkit work does not authorize its publication.

Legacy publication, source and evaluation records remain preserved. The [existing legacy website](https://Doron126.github.io/enterprise-infrastructure-orchestrator/) remains separate. The repository's [historical submission README](https://github.com/Doron126/enterprise-infrastructure-orchestrator/blob/fbdca98ceec95cb2f73e31aaf650033ca88f47df/README.md) is retained as historical context; its submission instructions are not toolkit installation instructions. Existing records retain their dates, scope and ownership.

Legacy maintenance remains bounded to compatibility, security and serious defects. Any later transition or retirement announcement needs a separate decision. Toolkit publication does not install or change the legacy Plugin.
