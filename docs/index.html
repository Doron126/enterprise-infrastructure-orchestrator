Enterprise Infrastructure Orchestrator

A skills-only ChatGPT plugin for explicit-invocation enterprise infrastructure engineering workflows.

What it does

Provides proportional, evidence-backed workflows for infrastructure troubleshooting, evidence reconciliation, low-level design, production change planning, customer readiness, current vendor verification when materially required, and Hebrew RTL documentation.

What it does not do

It does not operate an external MCP service, maintain an external database, collect telemetry independently, or execute infrastructure changes merely because it drafted a procedure.

This is an independent workflow plugin and is not affiliated with or endorsed by infrastructure vendors referenced in user tasks.
