Privacy Policy

Effective date: 5 September 2026

Enterprise Infrastructure Orchestrator is a skills-only ChatGPT plugin published by Doron Shamo. The plugin does not run an independent external service, MCP server, telemetry endpoint, user-account system, or external database.

Data handled by the plugin

The workflow may operate on information that a user provides to ChatGPT, such as technical questions, configuration excerpts, command output, screenshots, inventories, and documents. Processing occurs within the ChatGPT product and is subject to the user’s OpenAI account, workspace, and applicable OpenAI data controls.

No independent collection or storage

The publisher does not independently receive, collect, sell, or store user prompts, uploaded files, infrastructure evidence, or conversation content through this plugin. The plugin has no external backend to which it sends such data.

Secrets and credentials

Users should not provide passwords, private keys, API keys, tokens, recovery codes, or other secret values. The plugin’s workflow instructs ChatGPT not to request or reproduce secret values and to redact secrets encountered in supplied evidence where practical.

Third-party sources

When current vendor verification is materially required, ChatGPT may use capabilities available in the user’s ChatGPT environment, such as web research. Those capabilities are governed by the applicable ChatGPT and source-provider terms and controls; the plugin itself does not create a separate third-party connection.

Contact

For questions about this policy, use the support channel listed on the Support page.
